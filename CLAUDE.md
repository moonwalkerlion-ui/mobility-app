# Инструкции для ассистента (Claude)

## Язык
- Всегда общайся со мной на русском языке. Я начинающий разработчик.

## Объяснения перед действиями
- Перед каждым запросом разрешения (bash command, file edit, file write) сначала объясни простыми словами:
  1. Что эта команда / изменение делает
  2. Зачем это нужно
  3. Риски если есть
  4. Какой вариант мне выбрать и почему
- Объясняй как новичку. Технические термины расшифровывай в одном предложении.

## После каждого шага
- Пиши короткое резюме: что сделали, где находимся в общем плане проекта, что дальше.

## Рисковые операции
- Никогда не используй `sudo` без явного запроса.
- Никогда не удаляй файлы (`rm`) без явного подтверждения с моей стороны.
- Перед операциями `git push`, `git reset --hard`, drop database — всегда дополнительно проговаривай последствия.

## Контекст проекта
- Это Telegram Mini App для домашних тренировок и mobility, аудитория — русскоязычная СНГ
- Стек: Next.js 16 (App Router) + TypeScript + Tailwind + `@telegram-apps/sdk-react`
- Деплой: GitHub Pages (статический экспорт), автосборка через GitHub Actions.
  Адрес: https://moonwalkerlion-ui.github.io/mobility-app/ — сайт в подпапке,
  поэтому пути к файлам из `public/` идут через `asset()` (`app/lib/assets.ts`)
- БД: пока Telegram CloudStorage, без бэкенда
- Платежи: руками первые месяцы, потом Tribute
