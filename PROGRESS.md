# PROGRESS — состояние проекта

> Файл-«передача смены». Читается новой сессией Claude, чтобы сразу включиться в работу.
> Последнее обновление: 2026-07-29.

## Что это за проект
Telegram Mini App для домашних тренировок и mobility (подвижности суставов).
Аудитория — русскоязычная, СНГ. Пользователь — начинающий разработчик,
общение и объяснения — на русском (см. `CLAUDE.md`).

## Стек и ключевые решения
- **Next.js 16 (App Router) + TypeScript + Tailwind 4** — основа.
- **`@telegram-apps/sdk-react`** — работа с Telegram Mini App (данные пользователя и т.д.).
- **Статический экспорт** (`output: "export"` в `next.config.ts`) — потому что деплой на
  **Cloudflare Pages**, там нет Node-сервера. Из-за этого:
  - картинки без оптимизации (`images.unoptimized`),
  - `trailingSlash: true` (адреса вида `/page/`),
  - **нельзя** использовать серверные фичи Next (Route Handlers, Server Actions, SSR).
    Всё работает на клиенте.
- **БД пока нет.** Прогресс/настройки планируем хранить в **Telegram CloudStorage**
  (встроенное хранилище Telegram, привязано к пользователю). Бэкенда нет.
- **Платежи:** первые месяцы — вручную, позже подключим **Tribute**.
- ⚠️ **Важно про Next.js 16.** См. `AGENTS.md`: это НЕ тот Next.js, что в памяти модели —
  много breaking changes. Перед написанием кода сверяйся с локальной докой в
  `node_modules/next/dist/docs/`.

## Что уже сделано
- Инициализирован проект Next.js + TypeScript + Tailwind (коммит «Initial Next.js + Telegram Mini App setup»).

## Что дальше по плану (черновик, приоритеты сверху)
1. **Проверить запуск.** `npm run dev`, открыть локально; в идеале — прогнать внутри Telegram
   (через BotFather → Mini App, туннель типа cloudflared/ngrok на localhost).
2. **Инициализация Telegram SDK.** Сейчас используется только `retrieveLaunchParams()`.
   Разобраться, нужно ли вызывать `init()` из SDK, настроить тему/цвета, кнопку «назад»,
   разворот на весь экран (`expand`). Свериться с докой пакета.
3. **Контент тренировок.** Придумать модель данных (упражнение: название, длительность,
   картинка/гиф, описание; тренировка = набор упражнений). Пока можно захардкодить в TS-файле.
4. **Экраны:** список тренировок → экран тренировки → экран упражнения (таймер).
   Навигация с учётом статического экспорта (клиентские роуты).
5. **Сохранение прогресса** через Telegram CloudStorage (обёртка-хелпер над SDK).
6. **Деплой на Cloudflare Pages** (сборка `next build` → папка `out`), проверка боевой ссылки.
7. Позже: **платежи/подписка** (вручную, затем Tribute).

## Полезные команды
- `npm run dev` — локальный запуск (по умолчанию http://localhost:3000).
- `npm run build` — сборка статики в папку `out/` (её и деплоим на Cloudflare Pages).
