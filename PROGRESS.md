## Что это за проект
Telegram Mini App для домашних тренировок и mobility (подвижности суставов).
Аудитория — русскоязычная, СНГ. Пользователь — начинающий разработчик,
общение и объяснения — на русском (см. `CLAUDE.md`).

## Стек и ключевые решения
- **Next.js 16 (App Router) + TypeScript + Tailwind 4** — основа.
- **`@telegram-apps/sdk-react`** — работа с Telegram Mini App (данные пользователя и т.д.).
- **Статический экспорт** (`output: "export"` в `next.config.ts`) — потому что деплой на
  **Cloudflare Pages**, там нет Node-сервера. Из-за этого:
  - картинки без оптимизации (`images.unoptimized`),
  - `trailingSlash: true` (адреса вида `/page/`),
  - **нельзя** использовать серверные фичи Next (Route Handlers, Server Actions, SSR).
    Всё работает на клиенте.
- **БД пока нет.** Прогресс/настройки планируем хранить в **Telegram CloudStorage**
  (встроенное хранилище Telegram, привязано к пользователю). Бэкенда нет.
- **Платежи:** первые месяцы — вручную, позже подключим **Tribute**.
- ⚠️ **Важно про Next.js 16.** См. `AGENTS.md`: это НЕ тот Next.js, что в памяти модели —
  много breaking changes. Перед написанием кода сверяйся с локальной докой в
  `node_modules/next/dist/docs/`.

## Архитектурная идея: всё завязано на «зоны тела»
Зоны: плечи, overhead, грудной отдел, таз, задняя цепь, голеностоп.
- **Движение** (присед, рывок…) → какие зоны нагружает.
- **Дрил** (упражнение-подготовка) → какую зону прорабатывает + тип (активация/динамика/растяжка).
- **Тест гибкости** → балл по каждой зоне.
Тогда: разминка под движение = дрилы для его зон (активация+динамика); заминка = растяжка тех же
зон; персонализация = слабые зоны из теста поднимаются в приоритет. Добавить движение = указать зоны.
